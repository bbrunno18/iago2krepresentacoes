# Icaro Almeida e 2K Representações

Site institucional e catálogo B2B de representação comercial (Manaus/AM) para lojistas e atacadistas, com painel administrativo para marcas, produtos, categorias, FAQ, configurações e solicitações de catálogo/contato. Pedidos e interesse são direcionados ao WhatsApp.

**Tecnologias:** React 18, Vite, Tailwind CSS, Framer Motion, Lenis, Netlify Functions, Netlify Database (Postgres + Drizzle) e Netlify Identity.

## Rodando localmente
```bash
npm install
netlify dev --port 8889
```
