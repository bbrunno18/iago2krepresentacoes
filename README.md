## 🎯 O que é

Site institucional e **catálogo B2B** de uma representação comercial de Manaus/AM. Ele atende **lojistas, atacadistas e empresas** que querem conhecer as marcas, os produtos e falar com um atendimento comercial consultivo.

## ✨ Páginas e recursos

- 🏠 **Home** com apresentação da representação e das marcas
- 🏷️ **Marcas** e 🛍️ **Produtos**, organizados por categoria
- 📥 **Solicitar catálogo**, que transforma o interesse do lojista em contato comercial
- ❓ **Perguntas frequentes**, **Sobre** e **Contato**
- 🔐 **Painel administrativo** para gerenciar marcas, produtos, categorias, FAQ e configurações, sem mexer em código
- ✨ **Animações suaves** de rolagem e transição (Framer Motion e Lenis)
- 🔎 **SEO configurado** para ser encontrado por quem procura representação comercial

## 🧱 Tecnologia

React 18, Vite, Tailwind CSS, Framer Motion, Lenis, Netlify Functions, Netlify Database (Postgres com Drizzle) e Netlify Identity para o login do painel.

## 🚀 Como rodar

O código-fonte está na pasta `source-*`:

```bash
cd source-*
npm install
netlify dev --port 8889
```

O plano de evolução (banco de dados, API `/api/*`, carga inicial dos dados e login do painel) está em `PLAN.md`, dentro da pasta do código-fonte.
